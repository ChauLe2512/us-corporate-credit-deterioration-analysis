# U.S. Corporate Credit Deterioration Analysis

## Overview

This is a corporate credit analysis project examining six U.S. non-financial companies using accounting-based financial indicators from 2010–2024.

The project asks:

**Do the selected companies show deterioration in credit-relevant financial fundamentals over time and relative to industry peers?**

The analysis focuses on profitability, liquidity, leverage, debt-servicing capacity and operating cash-flow strength.

Python was used to calculate financial ratios, construct industry peer benchmarks and identify deterioration indicators. Tableau was used to visualize the final results for the six selected companies.

The project is intended as a financial-fundamental screening exercise rather than a credit rating, probability-of-default model or lending recommendation.

## Financial Ratios

Nine credit-relevant financial ratios were calculated.

### Profitability

1. **EBITDA Margin** = EBITDA / Sales

2. **EBIT Margin** = EBIT / Sales

3. **Return on Assets (ROA)** = Net Income / Total Assets

### Liquidity

4. **Current Ratio** = Current Assets / Current Liabilities

### Leverage

5. **Debt / Assets** = Total Debt / Total Assets

6. **Debt / Equity** = Total Debt / Common Equity

7. **Debt / EBITDA** = Total Debt / EBITDA

### Debt-Servicing Capacity

8. **Interest Coverage** = EBIT / Interest Expense

### Cash-Flow Capacity

9. **Operating Cash Flow / Debt** = Operating Cash Flow / Total Debt

**Total Debt** is defined as short-term debt plus long-term debt.

The Tableau dashboard focuses on EBITDA Margin, Debt / EBITDA and Interest Coverage, together with the project's overall Deterioration Rate.

## Deterioration Framework

The project combines two perspectives when assessing financial deterioration:

- **Time-series comparison:** whether a company's financial ratio deteriorated relative to its preceding consecutive fiscal year.
- **Peer comparison:** whether the company's financial ratio was weaker than the median of firms in the same 3-digit NAICS industry and fiscal year.

A deterioration signal is recorded only when both conditions are met.

For profitability, liquidity, interest coverage and cash-flow ratios, a decline is treated as deterioration.

For leverage ratios, an increase is treated as deterioration.

The Deterioration Rate measures the proportion of available financial indicators that both deteriorated over time and were weaker than industry peers *(Deterioration Rate = Number of deterioration signals / Number of valid deterioration tests)*.

For full details on data cleaning, sample construction, ratio treatment, peer benchmarking, deterioration rules and company selection, see [Methodology](docs/methodology.md).

## Limitations

This project focuses on accounting-based financial indicators and does not represent a complete professional credit assessment. It does not incorporate factors such as debt maturity schedules, covenants, external credit ratings, market-based credit measures or qualitative business-risk analysis.

The deterioration thresholds used in the analysis are project-specific screening rules rather than established credit-rating or default-prediction thresholds.
